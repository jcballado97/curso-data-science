# Laboratorio práctico 2.1 — Equipo B

## Caso de uso
Con el conjunto Gapminder (1,704 observaciones de 142 países entre 1952 y 2007) se aplican tres temas: Proyecto 7, visualización con Pandas y Matplotlib; Proyecto 8, distribuciones y correlaciones con Seaborn; Proyecto 9, preprocesamiento para un modelo. Los tres notebooks adaptan técnicas del curso a este conjunto de datos.

## Archivos para la entrega
- `Proyecto7_Visualizacion/`, `Proyecto_8_Visualizacion_Estadistica_Seaborn/` y `Proyecto_9_Gapminder/`: notebooks ejecutados, CSV y figuras. Los tres proyectos tienen un README individual.
- `Reporte_Proyectos_7_8_9_Equipo_B.pdf`: reporte de los proyectos asignados. Se incluye DOCX editable.
- `Presentacion_Equipo_B.pdf`: presentación final de 13 diapositivas, con PPTX editable.
- `Reporte_Otros_9_Temas_Equipo_B.pdf`: reporte de las pruebas 1 a 6 y 10 a 12, con DOCX editable.
- `evidencia_otros_nueve/Evidencia_otros_9_temas.ipynb`: código y salidas de esos nueve ejercicios.
- `gapminder_full.csv`: datos compartidos para el notebook complementario.

## Ejecutar en Google Colab
Abrir un notebook y cargar `gapminder_full.csv` en el panel Archivos. En los proyectos 7, 8 y 9 se puede usar la copia del CSV incluida en su carpeta. Luego seleccionar «Entorno de ejecución > Ejecutar todo». El entorno temporal de Colab pierde los archivos cargados al desconectarse.
